# CX Quota：一个给多 Codex 配置用的小工具

最近自己同时用几个 Codex 账号，慢慢发现最烦的不是开窗口，而是容易乱。

个人号、工作号、临时测试号一多，配置、登录、插件和会话很容易串。窗口开久了还会开始怀疑：这个窗口到底是谁？这个账号还有没有额度？要不要重新登录？

所以自己写了个小工具，叫 **CX Quota**。

它分两部分：

- `cx`：本地 Codex 账号和配置管理
- CX Quota：macOS 菜单栏里的额度查看器

`cx` 会把不同账号放到独立的 `CODEX_HOME` 里。登录状态、会话、本地设置和插件缓存默认都是分开的，所以可以在多个终端同时跑不同账号，不用反复退出、登录、切配置。

我自己现在一般是结合 **cmux** 用。

一个 workspace 里开几个窗口：个人账号放一个，工作账号放一个，临时测试再放一个。每个窗口跑自己的 Codex 配置，菜单栏再挂着各账号的额度。这样最大的感受不是“能多开账号”，而是终于不用老确认自己现在在哪个配置里了。

菜单栏目前能看：

- 5H 和周额度
- 重置时间
- 重置卡
- 登录是否失效
- 哪个账号正在刷新
- 哪个账号暂停了查询

登录失效时会提示重新登录；平时也可以手动刷新，不做后台轮询。

对我来说，`cx` 解决的是“配置别串”，菜单栏工具解决的是“别老进终端查额度”。

1. cmux 里多个 Codex 配置同时运行
2. 菜单栏账号额度总览

这个东西只做本地配置隔离和展示。登录、额度读取都还是走官方 Codex CLI；不复制认证文件、不共享账号、不合并额度，也不是拿来绕套餐或限额的。就是把自己有权使用的账号整理得顺手一点。

https://github.com/Fakexiaoer/cx-quota
